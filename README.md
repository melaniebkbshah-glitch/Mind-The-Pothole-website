# Mind the Pothole website
Static Vercel-ready website for Mind the Pothole.

## Deploy
1. Upload this folder to GitHub or drag it into a new Vercel project.
2. No build command is required.
3. Set the project root to this folder if it sits inside a larger repository.
4. Add your custom domain later in Vercel > Project > Settings > Domains.

## Important
The Steam links already point to:
https://store.steampowered.com/app/5031130/Mind_The_Pothole/
